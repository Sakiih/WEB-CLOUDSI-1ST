# Legacy Section Components

Folder ini berisi komponen section arsip / boilerplate awal yang saat ini tidak digunakan secara langsung di halaman aktif:
- `About.astro` (Digantikan oleh konten di `tentang.astro`)
- `Events.astro` (Halaman `acara.astro` mengimplementasikan layout event secara langsung)
- `Gallery.astro` (Halaman `galeri.astro` mengimplementasikan bento-grid khusus secara langsung)
- `Members.astro` (Halaman `anggota.astro` mengimplementasikan direktori anggota secara langsung)
- `Timeline.astro` (Digantikan oleh `PerjalananKami.astro`)

Komponen disimpan di sini untuk referensi jika sewaktu-waktu ingin digunakan kembali sebagai reusable component.
